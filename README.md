## 🌐 Project Overview
**ShenSiST Core** 是神思庭实验室推出的端侧超级个体认知中枢桌面版。该系统深度整合 Ollama 引擎，专为 1050Ti 等端侧算力卡优化，支持 5.9TB 级赛博资产的自动化创生、管理与可视化展示。



## 📥 Quick Start / 快速开始

1. **Download**: 直接下载本仓库中的 [Shensist_Core_V4_Final.tar.gz](./Shensist_Core_V4_Final.tar.gz)。
2. **Extract**: 
   ```bash
   tar -xzvf Shensist_Core_V4_Final.tar.gz
Install:

Bash
cd shensist_core
bash install_launcher.sh
Launch: 在桌面上找到 “神思庭控制台” 图标，右键选择 “Allow Launching” 后双击启动。

✨ Key Features / 核心特性
AI Asset Exporter: 基于 DeepSeek/Ollama 的一键式资产研报创生系统。

Holographic Viewer: 基于 curses 的黑客帝国风代码雨资产预览器。

One-Click Launcher: 自动生成桌面快捷方式，实现生产力工具化。

PWA Sync: 与 shensist.top 云端矩阵实时同步。
