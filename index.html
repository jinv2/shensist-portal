● CROSS-PLATFORM GUIDE (ALL OS)
🐧 Linux (原生推荐)
  • 环境检查：安装 Ollama 并确保后台进程已启动。
  • 解压：使用命令 tar -xvf Shensist_Core_V4.tar.gz。
  • 授权：执行 chmod +x install_launcher.sh。
  • 运行：执行 ./install_launcher.sh 自动创建快捷方式。
🪟 Windows (WSL / 环境方案)
  • 方案 A (推荐)：安装 WSL2 (Ubuntu)，按 Linux 步骤运行。
  • 方案 B (原生)：安装 Python 3.10+，启动 Win 版 Ollama。
  • 启动：在解压文件夹路径输入 cmd，执行 python bin/shensist_gui.py。
🍎 macOS (M1/M2 加速)
  • 环境：安装 macOS 版 Ollama。
  • 运行：进入文件夹执行 python3 bin/shensist_gui.py。
  • 注意：若提示权限不足，请在“隐私与安全性”中允许该应用。
