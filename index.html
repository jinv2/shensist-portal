ALL-PLATFORM DEPLOYMENT

🐧 Linux (原生推荐)
  • 解压：tar -xvf Shensist_Core_V4.tar.gz
  • 权限：chmod +x install_launcher.sh
  • 运行：./install_launcher.sh 脚本会自动创建桌面入口。
🪟 Windows (WSL / 环境方案)
  • 方案 A：安装 WSL2 (Ubuntu)，按照 Linux 步骤执行。
  • 方案 B：安装 Python 3.10+，启动 Windows 版 Ollama。
  • 启动：在解压目录执行 python bin/shensist_gui.py。
🍎 macOS (M1/M2 加速)
  • 环境：安装 macOS 版 Ollama。
  • 运行：在终端进入目录执行 python3 bin/shensist_gui.py。
  • 注意：若遇权限拦截，请在“系统设置 -> 隐私与安全性”手动通过。
